Challenge

Komthur, eine etablierte Mediaagentur, benötigte ein umfassendes Redesign ihrer Online-Präsenz. Die alte Website war nicht responsive, die SEO-Struktur war unteroptimiert und die User Experience ließ zu wünschen übrig.

Das Ziel war klar: Eine moderne, mobile-first Website mit integrierter SEO/SEA-Strategie, die nicht nur technisch brilliert, sondern auch emotional mit der Zielgruppe verbindet.

Lösung

Ich entwickelte ein ganzheitliches Konzept, das folgende Elemente integrierte:

  • ✓ Modern responsive Web Design (Mobile-First Approach)
  • ✓ UX/UI Optimierung mit User Testing
  • ✓ SEO-technische Optimierung (Core Web Vitals)
  • ✓ Integrierte SEA/Google Ads Strategie
  • ✓ Content Strategy & Informationsarchitektur
  • ✓ Analytics & Conversion Rate Optimization
